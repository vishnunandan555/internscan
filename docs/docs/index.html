💻 Python Example

import requests
data = requests.get("https://vishnunandan555.github.io/internscan/api/latest.json").json()

Deploy on Any $1/mo Nano Node or Linux VPS (<35 MB RAM)

Our bot script is built with pure Python 3 using standard libraries, requiring less than 15% of a 256MB RAM server.

git clone https://github.com/vishnunandan555/internscan.git
cd internscan/bot
pip install -r requirements.txt
cp .env.example .env && nano .env
python3 main.py

🛡️ Inviolable Data Invariants

  • Jobs are NEVER deleted: When an employer fills a role, it is set to active: false and timestamped with closed. Records are permanently retained to track posting flapping.
  • Stable Unique Identifiers (UIDs): Every posting has a stable uid = "{company_slug}:{external_id}" derived from the employer's official ATS requisition number.
  • Atomic Writes: All persistent databases write to temporary files first with POSIX atomic replacement to prevent corrupt reads.

About InternScan Platform Architecture

Direct ATS Synchronization

Positions are fetched directly from Workday, Greenhouse, SmartRecruiters, Lever, Oracle HCM, Eightfold, and custom corporate APIs every 3 hours.

Strict Memory Budget (< 35 MB RAM)

Both our scrapers and bot engine avoid heavy frameworks or headful browsers. Pure Python standard libraries ensure instant cold starts and minimal resource consumption.

Zero Fluff & Verified Engineering Roles

Rule-based categorization categorizes roles into Software, AI/ML, Data Engineering, Silicon/Hardware, Cloud/Infra, Mobile, and Security buckets.

100% Free & Open Source (MIT)

The entire scraping engine, database, website, and Telegram bot are licensed under MIT. Contributions and new company adapters are welcomed on GitHub.
