Developer & Community Integrations

Public API & Telegram Bot Documentation

Integrate our real-time verified internships with your Telegram channels, Discord bots, or campus placement trackers. 100% free, CORS-enabled, and auto-synced daily directly from career portals.

1

Deploy on Any ₹10/mo Nano Node or Linux VPS (<35 MB RAM)

Our bot script is built with pure Python 3 using standard libraries, requiring less than 15% of a 256MB RAM server.

git clone https://github.com/vishnunandan555/interntrack-india.git
cd interntrack-india/bot
pip install -r requirements.txt
cp .env.example .env && nano .env
python3 main.py
2

Configure Credentials in .env

Create a bot in 30 seconds via @BotFather on Telegram, add it to your channel as an Admin, and paste your values:

TELEGRAM_BOT_TOKEN=7123456789:AAHfkj...
TELEGRAM_CHAT_ID=@my_internships_channel
POLL_INTERVAL_SECONDS=1800
3

Keep Running 24/7 with systemd

Use the pre-packaged service unit so your bot boots automatically on server restart:

sudo cp interntrack-bot.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable --now interntrack-bot
sudo systemctl status interntrack-bot

💬 Interactive Bot Commands

Users in your group can message: /latest (new roles today), /active (all verified roles), /status (health check & memory).

💻 Python Example

import requests
data = requests.get("https://vishnunandan555.github.io/interntrack-india/api/latest.json").json()
for job in data.get("new_jobs", []):
    print(f"{job['company']}: {job['title']} -> {job['url']}")

⚡ JavaScript (Fetch)

const res = await fetch("https://vishnunandan555.github.io/interntrack-india/api/latest.json");

Set Repository Action Secrets

In your forked repo: Navigate to Settings → Secrets and variables → Actions and add two secrets:

  • TELEGRAM_BOT_TOKEN: Bot token from @BotFather
  • TELEGRAM_CHAT_ID: Channel username (e.g. @my_channel) or chat ID
3

Automated Push with Zero Server Costs

Your GitHub Actions workflow will execute automatically every night at 3:00 AM IST. When any new internship appears, it immediately pushes the notification to your Telegram chat!

About IndiaTech Internships Tracker

Direct Official Careers APIs

No stale job boards, aggregators, or expired postings. Every position is fetched directly from official employer ATS APIs (Workday, Greenhouse, SmartRecruiters, Lever, Oracle HCM, Eightfold) every 3 hours.

Focused on India Tech Hubs

Specifically filtered and categorized for engineering students and graduates seeking roles in Bengaluru, Hyderabad, Pune, Delhi-NCR, Chennai, Mumbai, and Remote India.

Automated Lifecycle & Zero Fluff

When an employer fills or pulls a listing from their portal, it is automatically removed from this tracker during the next cycle, saving you from applying to ghost jobs.

100% Free & Open Source

Operated via GitHub Actions. Developers and students can submit new company adapters or improvements directly on the GitHub repository.
