# 📊 Diagnostics & Run Logs (`logs/`)

The `logs/` directory contains runtime execution logs, synchronization summaries, and cumulative history generated by [`scraper/logger.py`](../scraper/logger.py).

---

## Log Files

- **`history.log`:** Cumulative log of newly added, closed, and reopened internships with ISO timestamps.
- **`scrape_summary.log`:** High-level summary of the most recent scrape cycle (duration, companies succeeded, active roles).
- **`scrape_full.log`:** Detailed debug log capturing HTTP status codes, rate-limit warnings, and errors during scraping.

---

## Retention Policy

- Scraper logs are generated and committed during scheduled GitHub Actions runs.
- Detailed logs capture up to 500 KB before rotating, keeping repository clones lightweight.
